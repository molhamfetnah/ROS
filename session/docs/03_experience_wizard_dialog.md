# Wizard Dialog to Select Fastest-Win Research Path

Use this as an interview-style decision flow.

## Wizard questions (in order)
1. Primary target in next 6–8 weeks?
   - A) Publishable experiment
   - B) Strong GitHub portfolio
   - C) Scholarship-ready research narrative
2. Strongest current stack?
   - A) Control theory
   - B) Robotics/ROS
   - C) ML
   - D) Embedded/real-time
3. Available compute/hardware?
   - A) Simulation only
   - B) Limited hardware
   - C) Full hardware access
4. Preferred contribution style?
   - A) Benchmark/reproducibility
   - B) Novel method
   - C) Engineering integration
5. Risk tolerance?
   - A) Low (quick certainty)
   - B) Medium
   - C) High (novel/high upside)
6. Writing readiness for academic commentary?
   - A) Ready now
   - B) Need evidence first
7. Time budget per week?
   - A) <8h
   - B) 8–15h
   - C) 15h+

## Scoring map
- If 1B or 1C + 4A + 5A/B → start with **FI-01/FI-02/FI-12**
- If 2A + 2B + 4B + 5C → prioritize **FI-05/FI-07**
- If 2C + 4B/C + 3A/B → prioritize **FI-08/FI-09**
- If 3C + 2D + 4C → include hardware validation in **FI-05/FI-06**

## Output profiles
1. **Fast credibility track**: FI-01 → FI-02 → FI-03 → FI-12
2. **Balanced track**: FI-01 → FI-06 → FI-08 → FI-12
3. **High-novelty track**: FI-07 → FI-05 → FI-10 (+ FI-02 for rigor)

## Fastest-win default (if uncertain)
Choose **Fast credibility track**. It gives visible results quickly and supports later high-novelty work.
